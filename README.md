# Comunic - Voip Tools

Ferramenta de diagnóstico de rede para troubleshooting VoIP, da [Comunic.se](https://comunic.se).

## Download

➡️ **[Baixar a versão mais recente (Windows)](../../releases/latest)**

1. Baixe o arquivo `Comunic - Voip Tools.zip` na página de Releases.
2. Extraia o .zip para uma pasta (por exemplo, `Documentos\Comunic - Voip Tools`).
3. Abra `Comunic - Voip Tools.exe`.

Não precisa instalar nada. Requer Windows 10 ou 11 (64 bits).
Se o Windows mostrar o aviso do SmartScreen, clique em **Mais informações → Executar assim mesmo**.

## O que ele faz

- **Visão geral (monitoramento):** acompanha em tempo real os seus servidores — ping, portas SIP (UDP/TCP/TLS), FQDN, limites de alerta, histórico e relatório por e-mail.
- **Scanner de Rede:** CGNAT, IP privado/público, gateway, DNS, jitter, buffer de jitter recomendado, MTU e varredura da rede local (telefones IP, fabricante, portas).
- **Ping e MTR:** latência, perda, jitter e MOS; traceroute contínuo no estilo WinMTR.
- **SIP ALG:** detecta se o roteador altera os pacotes SIP.
- **Portas e conexões, Captura SIP/RTP, Velocidade e banda.**
- **Diagnóstico completo:** um clique e um relatório HTML com tudo.

Também há uma versão de linha de comando (`comunic-voip-tools.exe`) para scripts e suporte remoto.

## Onde ficam os dados

- Configuração e log: `%APPDATA%\Comunic - Voip Tools`
- Relatórios e capturas: `Documentos\Comunic - Voip Tools`
